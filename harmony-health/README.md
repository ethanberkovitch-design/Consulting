# הרמוניה — Harmony Health

אפליקציית ליווי לירידה במשקל ומעבר לאורח חיים בריא, מבוססת על **שיטת 5 העמודים**
— סינתזה של גישות מדעיות מוכחות: גירעון קלורי מתון, חלבון מוגבר,
תזונה ים-תיכונית וגמישה, אימוני כוח וקרדיו, שינה איכותית ומיינדפולנס, ומדידה
שבועית לצורך התאמות מדויקות.

## הסטק
- React 19 + TypeScript
- Vite 8
- Tailwind CSS 4
- Supabase (אופציונלי — עובד גם עם localStorage)
- Recharts, Lucide React

## הרצה
```bash
npm install
npm run dev
```

## הבסיס המדעי — סינתזה של השיטות
- **CICO (Calories In/Out)** — הבסיס המתמטי, גירעון של 15–25% מה-TDEE.
- **חלבון מוגבר (1.6–2.2 גר'/ק"ג)** — שובע ושימור מסת שריר בזמן ירידה.
- **תזונה ים-תיכונית** — סיבים, שומנים בריאים, תזונה בת-קיימא.
- **Volumetrics** — עדיפות למזונות עם נפח גבוה וצפיפות קלורית נמוכה.
- **צום לסירוגין (אופציונלי)** — חלון אכילה של 10–12 שעות.
- **NEAT** — צעדים יומיים כמכפיל אנרגטי משמעותי.
- **אימוני כוח פרוגרסיביים** — שימור/בנייה של מסת שריר, קצב מטבולי.
- **CBT ומיינדפולנס** — זיהוי אכילה רגשית, החלפת הרגלים.
- **מעקב שבועי + התאמות** — לא ממתינים חודש; מזהים דפוסים ומתקנים.

## מבנה
```
src/
├── components/    (UI מודולרי, מסכים ורכיבים)
├── data/          (בסיס נתוני מזון, תרגילים, מתכונים)
├── hooks/         (state מקומי, פרופיל, יומן)
├── lib/           (מתמטיקה תזונתית, שיטה, supabase client)
└── App.tsx        (ניתוב מסכים)
```

## Supabase
כדי לחבר Supabase, צור קובץ `.env.local`:
```
VITE_SUPABASE_URL=...
VITE_SUPABASE_ANON_KEY=...
```
בהיעדר משתנים אלה, האפליקציה עובדת מקומית עם localStorage.
