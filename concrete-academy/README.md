# ברוכים הבאים לעולם הבטון: לומדה דיגיטלית

לומדת קליטה ורענון לעובדי מפעלי בטון, מחצבות ומפעל מוספים, מבוססת על חוברת ההדרכה לעובדים חדשים.

- **12 פרקים**, מסכים קצרים עם איורי החוברת, הדגמות מהשטח, "ככה עושים / ככה לא עושים", ושלוש "מעבדות" אינטראקטיביות (מים עודפים, צפיפות מים ממוחזרים, מחשבון ערמה).
- **80 שאלות מצבים**, 6-7 לכל פרק, עם הסבר לכל תשובה. השאלות והתשובות מעורבבות בכל ניסיון.
- **מעבר פרק:** 80% ומעלה, וכל שאלה שמסומנת "קריטית" (בטיחות או איכות) חייבת להיות נכונה.
- **מסלול לפי תפקיד:** פרקים 1-2 לכולם, ואחריהם פרקי התפקיד. שאר הפרקים נפתחים כרשות בסיום המסלול.
- **שני מצבים:** עובד חדש (כל התוכן) ורענון ("זכרו" ומבחן, והתוכן המלא בלחיצה).
- **תעודת סיום** עם הצהרת העובד ושורות חתימה לחונך ולממונה. מחליפה את טופס אישור ההדרכה (נספח ג').
- **לוח מנהלים** מוגן בסיסמה: מי התחיל, מי סיים, ציונים לפי פרק, סינון וייצוא לאקסל.
- **מילון מונחים** (כרטיסים הפוכים) ו**עשרת כללי הזהב**, זמינים מכל מסך.

## קבצים

| קובץ | מה זה |
|---|---|
| `dist/index.html` | הלומדה המלאה בקובץ אחד (כ-830KB, האיורים מוטמעים). נפתח בכל דפדפן. |
| `apps-script/Code.gs` | שרת התוצאות ב-Google Apps Script. |
| `apps-script/index.html` | אותה לומדה, להדבקה בפרויקט Apps Script. |
| `src/content.js` | **כל התוכן והשאלות.** כאן עורכים טקסט, שאלות ושיוך פרקים לתפקידים. |
| `src/app.js`, `src/styles.css`, `src/index.html` | מנוע הלומדה והעיצוב. |
| `assets/` | איורי החוברת (WebP). |
| `build.py` | בונה מחדש את שני קובצי ה-HTML אחרי שינוי ב-`src`. |

## הקמה עם Google Sheets (כ-10 דקות, פעם אחת)

1. ב-Google Drive יוצרים **גיליון חדש** (למשל "לומדת בטון - תוצאות").
2. בגיליון: **תוספים ← Apps Script** (Extensions ← Apps Script).
3. בעורך:
   - מחליפים את כל התוכן של `Code.gs` בתוכן הקובץ `apps-script/Code.gs`.
   - לוחצים **+ ← HTML**, קוראים לקובץ `index` (בלי סיומת), ומדביקים את כל התוכן של `apps-script/index.html`.
   - שומרים.
4. בוחרים בפונקציה `setup` בתפריט העליון ולוחצים **Run**. מאשרים את ההרשאות. נוצרים שני גיליונות: "יומן תוצאות" ו"סיכום עובדים".
5. **מחליפים את סיסמת המנהלים:** בפונקציה `setManagerPassword` משנים את `NEW_PASSWORD`, ומריצים אותה. (הסיסמה ההתחלתית היא `beton2026`, ואין להשאיר אותה.)
6. **Deploy ← New deployment ← Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone** (כדי שעובדים בלי חשבון Google יוכלו להיכנס)
7. מעתיקים את הכתובת שמסתיימת ב-`/exec`. **זה הקישור שנשלח לעובדים** (וואטסאפ, SMS, QR על לוח המודעות).

הלומדה רצה מתוך הכתובת הזו ושומרת כל תוצאה ישירות בגיליון. מנהלים נכנסים דרך "כניסת מנהלים" בתחתית הלומדה, או פותחים את הגיליון עצמו.

### חלופה: אחסון הלומדה במקום אחר

אם רוצים קישור בלי הפס של Google בראש העמוד (למשל אתר החברה, Netlify או SharePoint):

```bash
python3 build.py --api "https://script.google.com/macros/s/XXXX/exec"
```

ואז מעלים את `dist/index.html`. הלומדה תשלח את התוצאות לאותו גיליון.

## עדכון תוכן

עורכים את `src/content.js` ומריצים `python3 build.py`. אחר כך מדביקים מחדש את `apps-script/index.html` בפרויקט, ו-**Deploy ← Manage deployments ← Edit ← New version**, כדי שהכתובת תישאר זהה.

## חשוב לדעת

- **ההתקדמות נשמרת במכשיר** לפי מספר העובד. עובד שעובר למכשיר אחר יתחיל את הפרקים מחדש במכשיר החדש, אבל כל התוצאות שלו כבר בגיליון.
- **אין אימות זהות.** העובד מקליד שם ומספר עובד. זה מספיק להדרכה, אבל זה לא מבחן הסמכה. בגלל זה התעודה נחתמת גם על ידי החונך.
- **בלי אינטרנט** הלומדה ממשיכה לעבוד, והתוצאות נשלחות כשהחיבור חוזר.
- **פער בחוברת שכדאי ליישר:** בפרק 6 הטקסט אומר שמנהל האיכות משחרר מנה, ובנספח התשובות כתוב "הכימאי מחליט". בלומדה נוסחה תשובה שנכונה בשני המקרים. כדאי לתקן את החוברת.
