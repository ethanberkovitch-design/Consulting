# תורת הבטון — רמה מתקדמת (טכנולוגים)

תוכנית של 4.5 ימים (36 שעות, 11 מודולים — כולל מודול 0 "התקינה הישראלית לעומק" — כ-42% סדנאות) לטכנולוגים של החברה, על בסיס התקנים הישראליים בלבד.

- `תורת-הבטון-מתקדם-טכנולוגים.pptx` — מצגת ההדרכה (79 שקפים) על הטמפלט הארגוני
- `חוברת-תרגילים-טכנולוגים.xlsx` — חוברת התרגילים: דרישות ת"י 118 (טבלת מילוי), תכן תערובת, תיקון לחות, תערובות ניסיון, אבחון, עלות ותרחישים, בקרה סטטיסטית ו-CUSUM, טמפרטורת בטון, תיק תלונה
- מסמך התוכנית (סילבוס, לוח זמנים, הערכה והיערכות) — מסמך Claude נפרד
- `src/build_adv.py` — בונה את המצגת (משתמש ב-`../src/deckkit.py`)
- `src/workbook.py` — בונה את חוברת התרגילים

## בנייה מחדש

```bash
node ../src/assets.js ../build/assets
python3 src/build_adv.py ../template/solel-boneh-template.pptx ../build/assets "תורת-הבטון-מתקדם-טכנולוגים.pptx"
python3 src/workbook.py "חוברת-תרגילים-טכנולוגים.xlsx"   # ואז חישוב מחדש ב-Excel / LibreOffice
```

הדוגמאות במצגת משתמשות באותם נתונים כמו החוברת, כך שהמספרים בשקפים זהים למה שהמשתתפים רואים ב-Excel.
