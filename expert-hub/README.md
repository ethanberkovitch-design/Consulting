# Expert Hub

מערכת גג של סוכנים מומחים. משתמש רשום בוחר מומחה, מעלה מסמכים (PDF, Word, Excel, CSV, תמונות) ושואל שאלות. המומחה מנתח את החומר, מפנה למקור של כל טענה (מסמך ועמוד, סעיף תקן או קישור) ומפיק דוח מקצועי מובנה להורדה.

מומחים בגרסה הראשונה: בטון, פלדה, תכנון מבנים, פיננסי וניהולי.

## ארכיטקטורה

```
דפדפן (React + Vite)            Supabase                          Anthropic
─────────────────────           ─────────────────────────         ─────────────
בחירת מומחה, צ'אט, העלאה   →   Auth + Postgres (RLS)
Word/Excel → טקסט בדפדפן   →   Storage: expert-docs (פרטי)
                                Edge Function: expert-chat   →   Claude (streaming,
                                  · פרומפטים של המומחים          web search, PDF/תמונות,
                                  · מפתח ה-API                   prompt caching)
```

- **הפרומפטים של המומחים נמצאים בשרת בלבד** (`supabase/functions/_shared/experts.ts`). זה הקניין הרוחני של המוצר, והם לא נשלחים לדפדפן.
- **כל גישה לנתונים עוברת עם ה-JWT של המשתמש**, כך ש-RLS מבטיח שמשתמש רואה רק את השיחות והמסמכים שלו. גם פונקציית השרת לא יכולה לקרוא קבצים של משתמש אחר.
- **PDF ותמונות נשלחים למודל כמו שהם**, והוא קורא טבלאות, שרטוטים ותכניות. Word ו-Excel מומרים לטקסט בדפדפן.
- **ספריית ידע לכל מומחה** (`expert_library`): תקנים, מדריכים ונהלים שמנהל המערכת מעלה. היא מצורפת לכל שיחה עם אותו מומחה. רק משתמשים בטבלה `expert_admins` יכולים לערוך אותה.
- **חיפוש ברשת** פועל לנתונים עדכניים (רגולציה, מחירים, מהדורות תקנים), וכל מקור מוצג למשתמש.
- **דוח**: מופק לפי תבנית סעיפים קבועה לכל מומחה. ההורדה ל-PDF נעשית דרך מנוע ההדפסה של הדפדפן, שמציג עברית RTL וטבלאות נכון.

## הוספת מומחה

1. להוסיף רשומה ל-`EXPERTS` ב-`supabase/functions/_shared/experts.ts`: פרומפט, סעיפי דוח ומקורות מועדפים.
2. להוסיף כרטיס ציבורי ב-`src/experts/registry.ts` עם אותו `id`: שם, תיאור ושאלות פתיחה בעברית ובאנגלית.
3. לפרוס את הפונקציה מחדש. אין צורך בשינוי קוד נוסף.

## הקמה

דרישות: Supabase CLI ומפתח API של Anthropic.

```bash
# 1. מסד נתונים + אחסון (הפרויקט של pension-advisor משמש גם כאן)
supabase link --project-ref bqtajtacsulfcjzfbxmf
supabase db push                       # מריץ את supabase/migrations

# 2. מפתח ה-API: נשמר ב-secrets של הפונקציה בלבד
supabase secrets set ANTHROPIC_API_KEY=sk-ant-...
# אופציונלי: EXPERT_MODEL (ברירת מחדל claude-opus-5-5), EXPERT_EFFORT (ברירת מחדל high)

# 3. פריסת הפונקציה
supabase functions deploy expert-chat --no-verify-jwt   # the function verifies the user itself

# 4. הרשאת מנהל לספריית הידע (ב-SQL editor)
insert into public.expert_admins (user_id) values ('<user-uuid>');

# 5. צד לקוח
npm install
npm run dev        # פיתוח
npm run build      # dist/ מוכן לפריסה בכל נתיב (base יחסי)
```

## מה עוד לא בנוי (שלב הבא למוצר בתשלום)

- **חיוב ומנויים**: טבלת `expert_messages.usage` כבר שומרת את צריכת הטוקנים לכל תשובה, בסיס לתמחור ולמגבלות שימוש. חסרים עדיין Stripe, תכניות ומכסות.
- **ממשק ניהול לספריית הידע**: היום ההעלאה נעשית ישירות ב-Supabase Storage ובטבלה.
- **RAG**: כשספריית ידע של מומחה תעבור כ-20MB, צריך לעבור מצירוף מלא של המסמכים לשליפה לפי רלוונטיות (pgvector).
- **הערכת איכות**: סט שאלות בדיקה לכל מומחה, כדי למדוד שינויים בפרומפטים לפני שהם עולים לאוויר.
